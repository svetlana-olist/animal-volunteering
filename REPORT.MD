### Заметки для улучшения навыка размещения

- В новом интерфейсе VK форма публикации открывается разными путями: через «Предложить пост», напрямую через «Создать» или через «Создать» → «Пост». Навыку полезно поддерживать все три варианта.
- Файловый input нужно искать только внутри диалога «Новый пост». Глобальный `input[type=file]` может принадлежать альбому сообщества и отправить фотографии не туда. Во время этой задачи 5 фотографий Тора попали на экран добавления в основной альбом; все пять были сразу помечены удалёнными до повторной корректной загрузки в пост.
- VK иногда показывает не все вложения сразу: пятая фотография может появиться через несколько секунд после загрузки. Перед отправкой нужно дождаться окончания обработки и сравнить фактическое число кнопок удаления/карточек вложений с числом выбранных файлов; при расхождении не отправлять пост.
- Для надёжности медиа лучше добавлять по одному, каждый раз дожидаясь увеличения счётчика вложений. Даже при таком режиме после последнего файла полезна дополнительная короткая пауза.
- Текст из файла на Windows содержит `CRLF`, а редактор VK возвращает `LF`. Для точной автоматической сверки нужно нормализовать переводы строк, не ослабляя проверку самого текста.
- Перед выбором группы полезно проверять ссылку «Предложенные N»: на момент задачи в нескольких сообществах ещё находились наши прежние заявки, поэтому эти группы были пропущены.

Рязань и близлежащие](https://vk.com/club165925991) не было доступной кнопки создания/предложения записи. Эти адреса стоит перепроверить перед следующим циклом и при необходимости пометить в списке групп.
