Для размещения объявлений о животных используй skill `.agents/skills/vk-animal-posting/SKILL.md`.

Когда пользователь сообщает, что в картотеке появились новые животные, используй skill `.agents/skills/animal-intake/SKILL.md`, чтобы привести их карточки в порядок.

Для каждого животного храни в `animals/<вид>/<имя>/info.md`, где `<вид>` — `dogs` или `cats`, краткое описание устойчивых внешних признаков без перечня файлов. Называй каждый фото- и видеофайл с префиксом имени животного: `<имя>-<номер>.<расширение>`.

В `info.md` пользователь может указывать `Приоритет пиара: высокий` или `Приоритет пиара: низкий`. Не придумывай приоритет сам, сохраняй его при обновлении файла и учитывай при очередности публикаций: сначала высокий, затем низкий.

Если пользователь не указал конкретных животных для публикации, выбирай их случайным образом среди подходящих по правилам размещения. Учитывай приоритет пиара: сначала высокий, затем низкий; внутри одного приоритета выбирай случайно, а не по алфавиту или порядку папок.

Перед отправкой объявления выбирай медиафайлы только из папки текущего животного и проверяй одновременно: имя папки, префиксы файлов, соответствие фотографий описанию в `info.md` и наличие непустого текста из `advertisement.md`. Если `info.md` отсутствует или соответствие нельзя уверенно подтвердить, не отправляй объявление.

В конце каждой задачи, если есть изменения, проверяй их и делай git-коммит с понятным описанием без дополнительного запроса подтверждения. Включай изменения по выполненной задаче, в том числе обновления `REPORT.MD`; не добавляй временные файлы браузера и посторонние изменения. В итоговом ответе указывай хеш коммита.
