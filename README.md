# Animal Volunteering

Проект помогает искать дом животным с помощью автоматизации публикаций в сообществах ВКонтакте. В репозитории хранятся готовые объявления, фотографии и видео, список групп для размещения и отчет о выполненной работе.

## Структура проекта

- `animals/<имя>/` — материалы конкретного животного:
  - `advertisement.md` — текст объявления;
  - фотографии и видео для публикации.
- `VkGroups.md` — список групп ВКонтакте.
- `REPORT.MD` — журнал размещенных и предложенных публикаций.
- `.agents/skills/vk-animal-posting/` — skill автоматизации размещения.

## Как добавить животное

1. Создайте папку `animals/<имя>`.
2. Добавьте в нее текст объявления в файле `advertisement.md`.
3. Положите рядом фотографии и видео, которые нужно прикрепить к публикации.
