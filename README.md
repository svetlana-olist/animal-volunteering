# Animal Volunteering

Проект помогает искать дом животным с помощью автоматизации публикаций в сообществах ВКонтакте. В репозитории хранятся готовые объявления, фотографии и видео, список групп для размещения и отчет о выполненной работе.

## Структура проекта

- `animals/dogs/<имя>/` и `animals/cats/<имя>/` — материалы конкретной собаки или кошки:
  - `info.md` — устойчивые внешние признаки животного;
  - `advertisement.md` — текст объявления;
  - фотографии и видео для публикации.
- `VkGroups.md` — список групп ВКонтакте.
- `REPORT.MD` — журнал размещенных и предложенных публикаций.
- `.agents/skills/vk-animal-posting/` — skill автоматизации размещения.
- `scripts/vk-post.js` — безопасная пошаговая CLI для одного постоянного сеанса Edge.

## Как добавить животное

1. Создайте папку `animals/dogs/<имя>` для собаки или `animals/cats/<имя>` для кошки.
2. Добавьте в нее текст объявления в файле `advertisement.md`.
3. Положите рядом фотографии и видео, которые нужно прикрепить к публикации.

## Автоматизация VK

Установите зависимости командой `npm install`. Размещение выполняется небольшими проверяемыми шагами, а не отдельным скриптом для каждого животного:

```powershell
npm run vk -- prepare --animal "Марта" --group-url "https://vk.com/example" --media-reviewed
npm run vk -- session
npm run vk -- open-group
npm run vk -- fill --suggested-reviewed
npm run vk -- publish --token <reviewToken-из-fill>
```

`session` один раз запускает Microsoft Edge с постоянным профилем `.playwright-vk-profile` и затем подключается к тому же браузеру. Если требуется вход, пользователь выполняет его самостоятельно в оставшемся открытым окне, после чего команда запускается повторно.

CLI сохраняет этап в `.tmp-vk-post-state.json`. Перед фактическим кликом публикации записывается состояние `submit_attempted`. После этого повторная отправка программно запрещена: если результат неясен, разрешена только команда `npm run vk -- verify`.

Команда `prepare` работает без браузера и проверяет структуру карточки, префиксы медиа, наличие группы, интервалы из `REPORT.MD` и тематические ограничения. Флаг `--media-reviewed` является подтверждением, что агент уже визуально сверил каждое медиа с `info.md`.

Запустите безопасные офлайн-тесты командой `npm test`. Тесты не открывают VK и не могут опубликовать запись.
